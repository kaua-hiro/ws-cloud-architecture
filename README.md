# ☁️ AWS Cloud Services - Catálogo de Arquitetura

## 📌 Visão Geral
Este projeto consiste em uma página web responsiva construída puramente com HTML e CSS. O objetivo é mapear e detalhar cinco serviços críticos da infraestrutura AWS, exibindo-os em um grid de cards de alta qualidade com foco em design moderno (Dark Mode e Glassmorphism).

## 🛠️ Serviços Analisados
A arquitetura detalha os seguintes componentes:

* **Amazon ECS (Escolha Ideal):** Orquestrador de contêineres essencial para microsserviços modernos, desenvolvimento de SaaS e integrações de API complexas. Foi selecionado como o serviço mais adequado para fluxos de desenvolvimento dinâmicos usando Python, Node.js ou Next.js.
* **Amazon DynamoDB:** Banco de dados NoSQL serverless de ultra baixa latência.
* **Amazon S3:** Armazenamento de objetos com durabilidade inigualável (Data Lakes e Backups).
* **Amazon EMR:** Plataforma de clusters escaláveis para processamento de Big Data (Spark, Hadoop).
* **Amazon SageMaker:** Pipeline completo para construção, treinamento e deploy de Inteligência Artificial.

## 🚀 Como Visualizar o Projeto

Você não precisa de nenhum framework ou dependência para visualizar o resultado. Siga as instruções no seu terminal para baixar e executar:

Para clonar o repositório:

    git clone https://github.com/seu-usuario/aws-cloud-architecture.git
    cd aws-cloud-architecture

Para abrir a página diretamente no navegador (Exemplo no Windows):

    start index.html

Para abrir no macOS:

    open index.html

## 🎨 UI & UX Design
* **Componentização:** Cards uniformes com mesma estrutura de dados (Ícone, Título, Descrição, Checklist de Vantagens e Tags de Tecnologia).
* **Glassmorphism:** Efeitos de fundo desfocado com bordas translúcidas.
* **Micro-interações:** Elevação e brilho sutil ao passar o mouse sobre cada serviço.
* **Tipografia:** Fontes Inter (textos gerais) e Fira Code (tags técnicas) importadas via Google Fonts.
